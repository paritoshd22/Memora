## 2. Biggest visual opportunities (ranked by impact)

1. **Build the exterior (new).** Largest "anticipation" gap: façade, entrance doors, plaza, planting, paths, MEMORA signage, sky, exterior-to-atrium transition. Entirely new construction.
2. **Refine the atrium into a hero space.** Replace box-built architecture with profiled geometry (lathe columns, coffers, arches via extrude/shape; reuse helpers in `museumVisualStandards.ts`), add floor inlay and reflective stone detail. The central tree already has a refined builder: review it in screenshots first and only improve what looks weak.
3. **Introduce authored assets.** Add a small set of licensed CC0 GLB hero props (furniture, planters, lamps, toys) with procedural fallback (the loader and manifest already support this).
4. **Make rooms individually authored.** Give each room 3–5 signature architectural/furniture elements beyond palette changes.
5. **Real material maps.** Add a few licensed tileable texture sets (walnut, travertine, plaster) at 1024px–2K to replace the most visible canvas textures.
6. **Performance prerequisites for richer scenes.** Instance repeated elements, merge static geometry, budget lights. Needed *before* adding detail on mobile.
