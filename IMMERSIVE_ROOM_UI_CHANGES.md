# Immersive room UI changes

- Entering a category room now closes the music mini-player and controls guide.
- The temporary notification/tip banner and atrium quick-controls are hidden while inside a category room.
- The small museum/room header remains so the visitor can return to the atrium.
- Atrium navigation and elevator UI remain available outside category rooms.
- The underlying 3D room environment and its memory/object interactions are preserved.

Build validation was not run in this environment because project dependencies are not installed.
